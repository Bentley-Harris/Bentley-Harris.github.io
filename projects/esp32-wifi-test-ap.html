ESP32 Wi-Fi Test Access Point

2026 · Electronics & Embedded
  • ESP32
  • Wi-Fi
  • OLED
  • I²C

A small side project: an ESP32-C3 running as its own Wi-Fi access point, so I have a personal network in my room to test wireless projects on. A small OLED shows the network details, and one button flicks between screens.

Key details

  • Runs on a Waveshare ESP32-C3 board, powered over USB-C.
  • The ESP32 broadcasts its own network rather than joining an existing one, so it does not depend on any other Wi-Fi being around.
  • 0.96-inch two-colour OLED on I²C, with three screens: AP info (network name, password and channel), network (IP address and MAC address) and clients (how many devices are connected, and the uptime).
  • One push button cycles through the screens.
  • Built on a small breadboard. It is a quick test rig rather than a finished build.

Security

The network is password-protected, but honestly the password is mostly there for show. The board is switched off most of the time, and even when it is running, nothing is connected to it or relies on it, so there is nothing on the network to protect. It is also a separate network from the university Wi-Fi. The password is blurred out in the photos and the video anyway.

Why I built it

I wanted my own Wi-Fi network to test projects on. The ESP32-C3 is also the microcontroller I plan to move the fish tank controller onto, for its smaller size and onboard Wi-Fi, so this doubles as practice with it.
